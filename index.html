About the data

Every dataset is synthetic — generated by scripts/generate_data.py in each project — so the repo is fully reproducible without proprietary data. Schemas, distributions, and seasonality patterns mirror real e-commerce, SaaS, and fulfillment workloads. Random seeds are pinned, so re-running the pipeline produces identical output.
